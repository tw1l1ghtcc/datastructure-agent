## 模型与资料口径

显式AGENT_MOCK=true优先走开发模板；关闭Mock且后端配置Key才调用DeepSeek；两者都没有时聊天返回503。知识卡、动画和程序判分不依赖模型。空模型回复/上游失败可重试，限流、预算和用量控制继续保留。

二分查找卡片与两套过程题采用项目自编。聊天的 `sourceRefs` 为空，`knowledgeUsed` 为 `false`，`retrieval` 标为 `disabled`。独立知识查询保留原来源信息，后续引用教材时仍需核验出处。
