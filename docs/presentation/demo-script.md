# 正式程序演示脚本

核对基线：2026-10-23，main `1bd0d74`（PR #33）。先按根README启动生产服务；独立原型用3099端口，不能将原型录屏当成正式程序/真实模型证据。

1. 打开侧栏“课程目录”，展示8章规划；说明当前开放二分查找，其余待开发。点击“进入算法工作台”。
2. 点击“填入示例”，确认数组[1,3,5,7,9]、目标7，再点“开始分析”。
3. 单步到第2步，确认left=0、right=4、mid=2，源码与动画同步。播放默认1秒/步，标题栏仅全屏，Esc退出。
4. 打开对话球，问“为什么下一步要更新左边界？”；界面标注原运行/步骤。按实际配置说明真实模型或Mock；当前直接带状态、源码及历史调用模型，不演示聊天知识检索或知识卡出处。仅看到在线标志不代表模型对比已验收。
5. 收起聊天，播放到找到下标3；换目标4并重新开始分析，展示未找到和旧状态取消。
6. 打开“知识与辅导”独立阅读项目自编卡；进入“过程练习”按题目自己的固定情境作答、主动查看提示，在“错题与记录”重练并展示本机持久保存。
7. 说明切页保留运行/草稿，刷新仅恢复本机学习记录；模型失败时动画、知识卡和固定练习仍可使用。

录屏与现场演练使用实际运行版本，保留版本、配置和日期。尚无08三类真实对比及完整验收证据时，如实标待补，不用Mock替代效果结论。
