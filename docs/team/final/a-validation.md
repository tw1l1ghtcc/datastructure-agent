## 新版动画接入

A 包动画集成分支基于 main 的 `e945ab3`（[PR #66](https://github.com/tw1l1ghtcc/datastructure-agent/pull/66)）。第八章的七个正式排序入口使用 Plus 数组帧。可随步骤查看插入位置、折半边界、希尔分组、候选最小值和快速排序的枢轴。堆排序附加有效堆树，归并排序附加临时数组，两者使用 Plus SVG 舞台。

画面读取后端运行的当前快照。源码、变量、时间轴和问答共用原来的 `runId`、`stepIndex` 和 `sourceVersion`。浏览器验收运行 `node tests/a-workbench.browser.mjs`，Playwright 配置见[测试说明](../../../tests/README.md)。

本地静态检查、246 项自动化测试和 26 组后端验收通过。Edge 专项逐步对照七项的数组、源码高亮和 Mock 问答，并覆盖堆树缩减、归并临时区回看、空数组、单元素、带负数的重复值、整数边界及 390px 窄屏。通用窗口测试中的自定义代码示例断言在未改动的 `e945ab3` 基线上也失败。

## 使用

在工作台第八章选择7种新排序之一，输入`3,1,2`，开始分析，结果应为`[1,2,3]`。无需填写目标。逐步前进、回退、跳到结束，确认变量、源码与数组同步。

```powershell
npm.cmd start
```

打开<http://127.0.0.1:3000/>。本轮总进度见[最终进度表](progress.md)。
