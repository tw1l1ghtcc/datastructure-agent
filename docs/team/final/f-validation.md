# F 包交付与验收

七项算法从工作台「第三章 · 栈与队列」「第四章 · 串」及「第六章 · 图」运行。服务端生成独立快照，状态表、源码高亮、时间轴、步骤查询和问答共用本次运行的步号。[任务单](tasks/f-string-stack-dag.md) · [运行接口](../../architecture/api-contract.md#运行与步骤)

## 正常和边界用例

| 算法 | 示例与预期 | 边界检查 |
| --- | --- | --- |
| 括号匹配 | `([{}])` 匹配成功。每次入栈保存括号的原下标 | `([)]` 在下标 2 错配，`😀]` 在下标 1 出现多余右括号，`((` 的栈顶下标 1 未闭合 |
| 中缀转后缀 | `12+3*(4-2)` 输出 `12 3 4 2 - * +` | `8/4/2` 按左结合输出 `8 4 / 2 /`。相邻操作数、一元符号、未知词元或括号错误返回出错下标 |
| 表达式求值 | 后缀 `8 2 3 - /` 得 -8，中缀 `5/2` 得 2.5 | 栈下溢、栈残留、除零、非有限结果均终止在错误步 |
| 朴素匹配 | `aaaa` 查 `aa` 得 `[0,1,2]` | 空模式只返回 `[0]`，较长模式或失配返回空列表 |
| KMP | 两种跳转方式对 `aaaa` 查 `aa` 都返回 `[0,1,2]` | 覆盖空串、失配、重叠和 Unicode 码点下标。短二元串与独立穷举结果比较 1,920 次 |
| 表达式 DAG | `(2+3)*(2+3)` 得 25。两个乘法操作数引用同一加法节点，加法只求值一次 | 区分左右操作数顺序，拒绝不完整表达式和除零 |
| 关键路径 | A→B、A→C 工期 2，B→D、C→D 工期 3。总工期 5，展示两条关键路径 | 覆盖有向环、多源多汇、小数工期、非关键活动时差和平行活动 |

## KMP 人工核对

使用主串 `ababaababaca` 和模式串 `ababaca`。下标从 0 开始。最长相等真前后缀长度表为 `[0,0,1,2,3,0,1]`。第 0 位的 `next` 为 -1，后续 `next[j]` 取 `prefix[j-1]`。若回退位与当前位置的模式字符相同，`nextval` 继续沿已算好的 `nextval` 跳转。

| 事件 | next | nextval |
| --- | --- | --- |
| 预处理完成 | `[-1,0,0,1,2,3,0]` | `[-1,0,-1,0,-1,3,-1]` |
| 主串下标 5 失配 | 模式下标 5 → 3 → 1 → 0，主串下标保持 5 | 模式下标 5 → 3 → 0，主串下标保持 5 |
| 完成匹配 | 起点 5，匹配结束后保留长度 1 的重叠前缀 | 起点 5，匹配结束后保留长度 1 的重叠前缀 |

## 复现

```powershell
npm.cmd run check
node --test --test-concurrency=1 tests/final-f.test.mjs tests/final-f-native.test.mjs
node tests/f-workbench.browser.mjs
```

专项用例 14 项通过，其中 7 项从运行返回的展示源码提取 C++，使用仓库的 Open Watcom 编译、链接和实跑。Edge 验收覆盖七项示例、状态表、前进、回退、重置、源码高亮、步骤查询和 Mock 问答，并检查有向环可以正常展示。

表达式支持二元加减乘除，首版拒绝一元符号。分词器只接受非负整数词元和 ASCII 空白，除法使用浮点数。关键路径按千分之一的单位做整数运算，最多展示八条路径，更多路径通过结果字段提示。

展示源码的串输入用 Unicode 码点数组，图顶点以零基索引传入。各入口沿用已有运行接口和状态表。独立验收由 01 协调，02 可根据相同步骤快照继续联调图和栈的动画表现。
